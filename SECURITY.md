# Security reporting

Use the Security tab in the public FetchVolt repository if private vulnerability reporting is enabled. Otherwise open an issue asking the maintainer for a private reporting channel; omit exploit details until that channel is established. Do not publish private URLs, credentials, logs, local addresses or recovery data.

FetchVolt previews are unsigned and may contain defects. Use current Windows security protections. HTTPS, integrity verification, Mark of the Web and Defender scanning reduce risk; they do not guarantee every file is safe or the absence of vulnerabilities. No downloaded file is executed automatically.
